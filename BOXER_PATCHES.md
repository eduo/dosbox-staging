# Boxer-specific DOSBox-Staging integration points

This file documents intentional Boxer divergences from upstream DOSBox-Staging. These are not a list of all code differences; they are the integration points that Boxer depends on and that must be preserved during future DOSBox-Staging merges.

| Subsystem | Source marker(s) | Source file(s) | Relevant function/class | What Boxer changed | Why Boxer needs the change | Boxer component that depends on it | What could break if overwritten | How to test after a merge |
